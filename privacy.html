Hero Daily Uploader - Privacy Policy

Last updated: October 25, 2026

Hero Daily Uploader is a private desktop tool used only by the owner of the YouTube channel "Hero Daily" (@herodailynews, https://www.youtube.com/@herodailynews). It uploads the owner's own videos to the owner's own channel using the YouTube API Services.

1. YouTube API Services

This tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service: https://www.youtube.com/t/terms

Google Privacy Policy: https://policies.google.com/privacy

2. What data is used

- The OAuth 2.0 access/refresh token for the owner's Google account (scopes: youtube.upload, youtube.readonly).

- The owner's own channel ID and channel title (to confirm the correct channel).

- The owner's own video files, titles and descriptions that are uploaded.

No data of any other user is collected, accessed, stored or shared.

3. How data is stored

The OAuth token is stored only in a local file on the owner's own computer. Nothing is sent to any server other than Google/YouTube APIs. No data is sold or shared with third parties.

4. How to delete data / revoke access

- Revoke access at any time: https://security.google.com/settings/security/permissions (remove "Hero Daily Uploader").

- Deleting the local token file removes all stored data. Stored data is deleted within 7 days after access is revoked.
